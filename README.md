# 🤖 STAR LINK CODE HACK BOT

ဒီ Bot သည် **Ruijie Networks** (Star Link) Portal များအတွက် Voucher Code များကို Brute Force နည်းဖြင့် အလိုအလျောက်ရှာဖွေပေးသော Telegram Bot ဖြစ်သည်။

> ⚠️ **သတိပေးချက်**: ဤသည် ပညာရေးဆိုင်ရာနှင့် ကိုယ်ပိုင်စမ်းသပ်မှုအတွက်သာ ရည်ရွယ်ပါသည်။ တရားမဝင်သုံးစွဲခြင်းအတွက် တာဝန်ယူမည်မဟုတ်ပါ။

---

## ✨ အဓိကလုပ်ဆောင်ချက်များ

- 🔢 **Voucher ရှာဖွေခြင်း**: ဂဏန်း (6-9 လုံး), အင်္ဂလိပ်အက္ခရာ (a-z), နှင့် ရောထွေး (Mixed) ပုံစံများဖြင့် ရှာဖွေနိုင်သည်။
- 🔗 **Portal URL ထည့်သွင်းခြင်း**: `/portal` command ဖြင့် ပစ်မှတ် Portal URL ကို သတ်မှတ်နိုင်သည်။
- 📋 **Success Code သိမ်းဆည်းခြင်း**: တွေ့ရှိသော Code များကို GitHub (result.json) တွင် အလိုအလျောက် သိမ်းဆည်းပေးသည်။
- 🔄 **Recheck**: ယခင်က တွေ့ခဲ့သော Code များကို ပြန်လည်စစ်ဆေးပေးသည်။
- 👑 **Admin Panel**: User များအတွက် Key ထုတ်ပေးခြင်း၊ ဖျက်ခြင်းနှင့် Broadcast ပို့ခြင်းတို့ ပြုလုပ်နိုင်သည်။
- 🛡️ **Paid User System**: Key ဖြင့် အသုံးပြုသူများကို စီမံခန့်ခွဲနိုင်သည်။

---

## 📁 လိုအပ်သော GitHub ဖိုင်များ

Bot အလုပ်လုပ်ရန်အတွက် Repository Root တွင် အောက်ပါဖိုင်များ ရှိရမည်-

1.  **`auth_list.json`** (ဗလာ `{}`) - Registered User များနှင့် ၎င်းတို့၏ Key သက်တမ်းကို သိမ်းသည်။
2.  **`result.json`** (ဗလာ `{}`) - တွေ့ရှိသော Success Code များကို User ID အလိုက် သိမ်းသည်။
3.  **`.gitignore`** - (Optional) Python cache နှင့် temporary ဖိုင်များအတွက်။
4.  **`requirements.txt`** - (Optional) Python packages စာရင်း။
